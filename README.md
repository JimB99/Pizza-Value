# Pizza-Value

Find out which pizza gives you the most food for your money — with crust excluded.

## Run locally

```bash
python -m http.server 8080
# Open http://localhost:8080
```

## Tests

```bash
npm test
```

## Deploy (GitHub Pages)

1. Push to GitHub
2. Repo → Settings → Pages → deploy from `main` branch, `/` root
3. Open `https://<username>.github.io/Pizza-Value/`

Install via **Add to Home Screen** for offline use after the first visit.
